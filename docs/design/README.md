# 设计稿存档

Pixso 是本地服务，关掉 Pixso 或换机器就读不到。所以**确认过的设计稿必须在这里留一份**——
截图 + 节点 id + 确认时间。仓库是唯一可追溯的地方。

## 一份记录长什么样

文件名：`<页面>-<用途>.md`，例如 `device-strip-list.md`

```markdown
---
page: pages/device
pixso_node: "12:345"
confirmed: 2026-11-08
---

# 设备页 · 灯链列表

![截图](./device-strip-list.png)

## 覆盖的态

- 空态：无灯链
- 常态：三条灯链，其中一条离线
- 错误态：连接中断

## 与规范的偏离

无。如偏离写成：`XXX 由 24rpx 改为 20rpx，原因：…`
```

截图与 md 同名放同目录。

## 规则

- **只有你确认过的设计稿才进这里。** 未确认的留在 Pixso，不入库。
- 记录一旦入库，**不覆盖不删除**。设计变更时新增一份，文件名带序号：`device-strip-list-2.md`。
- 代码改动涉及页面结构时，PR 描述必须指向这里的某一份记录。
