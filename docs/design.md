# 设计规范

**灰底柔光**：清晨的智能灯光面板——浅灰画布、纯白卡片、柔和投影、蓝色唯一强调。
**设备与场景是主角**（图标砖、大控件），界面退成安静的冷调底。

> **所有页面样式必须引用本文定义的变量，禁止手写颜色值与字号。**
> 改视觉先说清改哪一条，改完回来改这里，再改代码。

## 1. 适用与偏离

参照智能家居参考稿（2026-11-08 确认，画布改为浅灰），针对微信小程序做四处偏离：

| 偏离 | 参考稿 | 本项目值 | 原因 |
|---|---|---|---|
| 画布 | 桌面网页 | **393 × 852**（iPhone 15 / 主流安卓同档） | 按当前主流手机尺寸绘制 |
| 字体 | 定制几何无衬线 | 系统栈 | 小程序不能打包字体；系统中文字体最接近 |
| 字号 | px 直接标注 | rpx（750 / 393 ≈ 1.91 倍） | 等比换算，字号表已直接给 rpx |
| 字距 | 常规 | 微标签 +0.05em | 保留宽字距签名；其余角色 0 |

其余照参考稿：纯白卡、**柔和蓝灰投影**、蓝色开关与滑块、绿色在线点、图标砖行卡。

**设计稿画布固定 393 × 852。** 所有页面都按这个尺寸出稿。

## 2. 布局

**8pt 网格**，在 WXSS 里是 16rpx 的倍数。

| 项 | 值 | 说明 |
|---|---|---|
| 页面左右边距 | 32rpx | 全项目统一 |
| 卡片内边距 | 48rpx（大卡）/ 32rpx（行卡） | |
| 双列列间距 | 24rpx | 设备卡两列之间 |
| 列表行间距 | 16rpx | 同组行卡之间 |
| 区块间距 | 48rpx | 有标题分隔的段落之间 |
| 标题与内容间距 | 16rpx | |
| 最小触摸区 | 88rpx | 44pt，**任何可点元素不得小于此** |
| 页面底部留白 | `calc(160rpx + env(safe-area-inset-bottom))` | 给 tabBar 让位 |

### 页面层级

```
设备（tab）  ──点设备卡──▶  设备详情  ──点灯链行──▶  灯链详情（部位列表）
   └──标题右 + ──▶ 添加菜单 ──点「添加设备」──▶ 添加设备（搜索页）

场景（tab）
我的（tab）
```

- **设备 tab = 设备列表页**，双列卡片网格。
- **标题右侧是「+」**，点开添加菜单（仅一项「添加设备」），进独立搜索页。
- 下钻页面都有返回，tabBar 保持在底部。

## 3. 字体

```
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif;
```

数字（亮度、dBm、计数）加 `font-variant-numeric: tabular-nums`。

| 角色 | 变量 | 字号 | 字重 | 行高 | 字距 | 用途 |
|---|---|---:|---:|---:|---:|---|
| 大标题 | `--text-display` | 62rpx | 600 | 1.25 | -0.8rpx | 每页最多一个 |
| 大数字 | `--text-number` | 80rpx | 600 | 1.2 | -1.6rpx | 亮度百分比，tabular |
| 区块标题 | `--text-heading` | 48rpx | 600 | 1.25 | -0.8rpx | 「灯链」「部位」 |
| 卡片标题 | `--text-card` | 40rpx | 600 | 1.38 | 0 | 卡片内标题、设备名 |
| 正文 | `--text-body` | 32rpx | 400 | 1.5 | 0 | 默认正文 |
| 辅助 | `--text-secondary` | 28rpx | 400 | 1.45 | 0 | 副标题、元信息 |
| 微标签 | `--text-label` | 24rpx | 500 | 1.2 | 0.05em | 眉标、状态行、chips |
| 说明 | `--text-caption` | 20rpx | 400 | 1.4 | 0.05em | 脚注 |

字重只用 **400 / 500 / 600**。不用 700。

## 4. 颜色

浅灰中性是底，**蓝是唯一强调色**。绿只表达「在线/成功」，红只表达故障。

### 表面

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#F2F4F7` | 页面底色（浅灰画布） |
| `--surface` | `#FFFFFF` | 白卡：主卡、行卡 |
| `--surface-nested` | `#EDF0F4` | 图标砖、卡内嵌套面 |
| `--accent-wash` | `#DDEBFF` | 选中/激活的浅蓝底 |
| `--hairline` | `#E4E8EE` | 发丝分隔线 |

### 文字

| 变量 | 值 | 用途 |
|---|---|---|
| `--text-primary` | `#17233D` | 标题（深海军蓝，不透明 100%） |
| `--text-body` | `#33415E` | 正文 |
| `--text-secondary` | `#5F6F87` | 次级文字、副标题（白卡 5.11:1） |
| `--text-tertiary` | `#8D9CB2` | 占位、禁用（仅装饰/禁用，不承载信息） |

### 强调与语义

| 变量 | 值 | 用途 |
|---|---|---|
| `--accent` | `#2A61E8` | 蓝：开关、滑块、选中描边、主按钮、导航当前点 |
| `--accent-press` | `#2456D6` | 蓝按下态 |
| `--ok` | `#3FBF6F` | 绿：已连接、成功 |
| `--dot-active` | `#E5484D` | 红：未连接、设备离线、错误（**只表故障**） |

**规则**：
- 蓝只做控件与动作；绿只做在线/成功；红只做故障。一个状态一个色，必须同时有文字。
- 界面不用纯黑；最深是 `--text-primary`。
- 封面图、场景缩略图、灯效预览不受限（见 §11）。

## 5. 圆角

| 用途 | 值 |
|---|---:|
| 大卡（设备卡、详情主卡、底部导航） | 48rpx |
| 行卡（灯链行、搜索结果行、菜单） | 32rpx |
| 图标砖、小控件 | 24rpx |
| 胶囊（按钮、chips、开关） | 9999rpx |

## 6. 层次与阴影

**投影是本风格的骨架**（对前版「无阴影」的推翻）。只用三档，中性灰调、向下扩散：

| 变量 | 值 | 用途 |
|---|---|---|
| `--shadow-card` | `0 16rpx 40rpx rgba(88,100,122,0.14)` | 大卡、底部导航 |
| `--shadow-soft` | `0 8rpx 24rpx rgba(88,100,122,0.09)` | 行卡、图标砖、浮层菜单 |
| `--shadow-knob` | `0 4rpx 10rpx rgba(23,55,94,0.18)` | 开关滑钮、滑块旋钮 |

辅助层次：发丝线 2rpx `--hairline`（左内缩 32rpx）+ 表面色阶。
**卡片最多两级嵌套。** 禁止更深的投影或带色描边发光。

## 7. 控件

### 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主 | 填充 `--accent`，白字，胶囊，`--shadow-soft` | 每屏最多一个（添加设备、重新扫描、重新连接） |
| 次 | 填充 `--surface`，文字 `--text-body`，胶囊，`--shadow-soft` | 并列次要动作 |
| 文字 | 无底，文字 `--accent` | 轻量动作（停止扫描、去设置） |
| 危险 | 无底，文字 `--dot-active` | 删除 |

高度 88rpx，字号 32rpx。并列按钮之间 16rpx。

### 开关

用原生 `switch`，`color` 设为 `--accent`。不自绘。

### 滑块

轨道 8rpx 高，圆角胶囊；未填充 `--surface-nested`、已填充 `--accent`。
滑块直径 40rpx，白色，带 `--shadow-knob`。

### 设备卡（设备列表页，双列）

**两列网格**，列宽 332rpx，列间距 24rpx。
卡片 `--surface` 白卡，48rpx 圆角，`--shadow-card`，`overflow: hidden`。

**卡片高度不写死，按可用空间反推。** 两行卡片 + 行间距正好填到 tabBar 上方：
`cardH = (可用高 − 行间距) / 2`。固定高度在 852 画布上会留下近 250pt 空白，
窄屏又会溢出。封面吃卡片减掉信息区后的剩余高度。

- **封面**：内缩 24rpx 放一块图标砖（`--surface-nested`，24rpx 圆角），
  砖内一枚灯泡图形（暖黄玻璃 + 灰座）。但灯泡固定 104rpx 见方，**不随封面放大**。
- **状态 chip**：封面左上角一枚白底胶囊，写「已连接」（蓝字）或「离线」（次级字色）。
  状态词只在这里出现一次。
- **信息区**：内边距 24rpx。设备名 `--text-card` 600 `--text-body`，单行截断。
  状态行：12rpx 圆点（在线 `--ok` / 离线 `--text-tertiary`）+ 灯链数 `--text-label`；
  右侧原生 switch。**离线卡的 switch 画成禁用**。
- 整卡可点进详情；switch 独立可点，不触发下钻。

**为什么状态词在 chip 而不是状态行**：174pt 宽的卡扣掉内边距与 switch 后只剩约 95pt，
放不下「2 条灯链 · 离线」。位置不够就换位置，不缩小字号也不裁字。

### 下钻行（灯链 / 部位）

白卡，32rpx 圆角，高 128rpx，行间 16rpx，`--shadow-soft`。
左侧名称 + 元信息两行；部位行左侧 16rpx 色点（`--accent`，未分配 `--text-tertiary`）；右侧 `›`。

### 标题右侧「+」与添加菜单

页面标题右侧一枚 72rpx 白色圆钮（`--shadow-soft`，蓝色加号）。
点开后变 `--accent-wash` 底 + `--accent` 描边，下方展开 400rpx 宽添加菜单
（白卡 32rpx 圆角 + `--shadow-soft`），右对齐，浮于内容之上。
菜单仅一项：64rpx `--accent-wash` 方块内蓝色加号 + 「添加设备」+ 副文案「搜索附近的灯控」。

### 添加设备搜索页

独立页面：返回 + 眉标「添加设备」+ 标题「附近的灯控」。
状态行（微标签：搜索中蓝点、已停止灰点）+ 右侧结果计数。
结果行：白卡 32rpx 圆角 `--shadow-soft`，高 144rpx；左侧 80rpx 图标砖，中间广播名 +
配对说明，右侧 dBm 或「已配对」浅蓝 chip。点一台即连接。
无结果 10 秒：空态卡 + `--accent-wash` 权限卡（红点 + 检查定位与蓝牙权限 + 「去设置」）+ 主按钮「重新扫描」。

### 底部导航

白底胶囊浮条（48rpx 圆角，`--shadow-card`），三项等距：设备 / 场景 / 我的。
**每项是「24pt 描边图标 + 间距 8pt + 微标签文字」的上下一小列，整组在高度内居中。**
条高 128rpx（图标、间距、文字行、上下内边距各 16rpx 累加）。

- 图标一律 1.5pt 描边、无填充、无渐变、不用 emoji。三个图标画在 20×20 安全区内，视野一致。
- 选中项：图标 `--accent`，文字 `--text-body`；未选中：两者都 `--text-secondary`。
- **红色不得用于当前选中。**
- 选中不靠颜色单独表意：图标填色 + 文字字色是两个通道，且文字始终在场。

图标语义：设备 = 灯泡轮廓；场景 = 三条长度递减的时间轴；我的 = 人像轮廓。

### 微标签（Tracked Label）

`--text-label` + 前缀 8rpx 彩色圆点（默认 `--accent`；故障 `--dot-active`；停止/离线 `--text-tertiary`）。
区块眉标、状态行的唯一写法。

## 8. 动效

| 项 | 值 |
|---|---|
| 时长 | 200ms（小控件）/ 280ms（页面转场）/ 320ms（较大面积） |
| 曲线 | `cubic-bezier(0.32, 0.72, 0, 1)` |
| 入场 | `opacity 0→1` + `translateY(8rpx→0)` |
| 按下 | `scale(0.97)`，120ms |
| 展开 | 高度或透明度过渡，不弹跳 |

**不做**：视差、滚动监听动画、超 400ms 装饰动画、自动轮播、闪烁。

`prefers-reduced-motion: reduce` 时全部动效降为 0ms。

## 9. 文案

- **按钮 = 动词 + 宾语**。「添加设备」「保存布局」
- **标题 = 名词短语**。「灯链」「部位」
- 数字与单位之间留一个空格：`30 颗`、`500 ms`
- 不用感叹号，不用「请」，不用「您的」
- 空态必须给下一步动作：「还没有设备。点右上角 + 添加附近的灯控」
- 错误信息说**是什么 + 怎么办**

## 10. 禁令

1. 三档投影之外的任何阴影（更大扩散、带色发光、内阴影）
2. 灰底上灰字（对比不足）；正文用纯黑
3. 卡片超过两级嵌套
4. emoji 当图标
5. 页面样式出现 hex 或字号硬编码（必须走变量与字号表）
6. 可点元素小于 88rpx
7. 用颜色单独传达状态（必须同时有文字或图标）
8. 绿色/红色用于非语义场景（绿只在线成功，红只故障）
9. 装饰性渐变（封面插画、场景缩略图、灯效预览除外）

## 11. 封面图与灯效预览的特殊规则

封面插画、场景缩略图、灯效预览区是**内容**，不是界面。它们是全项目唯一允许：
- 出现任意颜色与渐变
- 使用照片素材

但它们的**容器、标签、控件**仍受本文约束。

## 12. 与 Pixso 的对应

设计稿只画到**结构与关键态**：区块划分与层级、空态 / 加载 / 错误 / 选中。
颜色用本文变量名标注，不标 hex。画布固定 393 × 852。
