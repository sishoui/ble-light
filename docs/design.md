# 设计规范

**Marco 冷调纸感**：晨光里的记事本——近白画布、纸感白卡、宽字距小标签、圆角胶囊。
**颜色是配给品**：整页几乎全中性，紫罗兰 / 信号蓝 / 珊瑚渐变只做微小的功能性标点。

> **所有页面样式必须引用本文定义的变量，禁止手写颜色值与字号。**
> 改视觉先说清改哪一条，改完回来改这里，再改代码。

## 1. 适用与偏离

参照 Marco 风格参考稿（2026-11-08 确认），针对微信小程序做四处偏离：

| 偏离 | 参考稿 | 本项目值 | 原因 |
|---|---|---|---|
| 字体 | Maison Neue / Graphik / Neue Montreal 三套定制字体 | 系统栈 | 小程序不能打包字体；系统中文字体最接近 |
| 字号 | px 直接标注 | rpx（1px ≈ 2rpx） | 小程序 750rpx = 视口宽，等比换算 |
| 阴影 | 1–3px 低投影 | 完全无 | 参考稿允许耳语级投影，但小程序真机渲染参差，层次改由边界与色阶承担 |
| 字距 | 微标签 0.05–0.2em 正字距 | 保留 | 小程序支持 `letter-spacing`，这是本风格的手写签名单式感来源，照抄 |

其余照参考稿：Linen 画布、Paper 白卡、18–32px 大圆角、全胶囊交互件、彩色只做标点。

## 2. 布局

**8pt 网格**，在 WXSS 里是 16rpx 的倍数。

| 项 | 值 | 说明 |
|---|---|---|
| 页面左右边距 | 32rpx | 全项目统一，不按页面调 |
| 卡片内边距 | 48rpx | 大卡片；小控件 32rpx |
| 卡片间距 | 16rpx（同一组列表行之间）/ 48rpx（独立卡片之间） | 卡内松、卡间紧 |
| 区块间距 | 48rpx | 有标题分隔的段落之间 |
| 标题与内容间距 | 16rpx | 标题下方 |
| 最小触摸区 | 88rpx | 44pt，**任何可点元素不得小于此** |
| 页面底部留白 | `calc(160rpx + env(safe-area-inset-bottom))` | 给 tabBar 让位 |

## 3. 字体

```
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif;
```

数字（亮度、dBm、计数）加 `font-variant-numeric: tabular-nums`。

**字距曲线是本风格的签名**：小字加宽（+0.05em 起），大字收紧（-0.013em）。
绝不在整个字阶上用同一个字距值。

| 角色 | 变量 | 字号 | 字重 | 行高 | 字距 | 用途 |
|---|---|---:|---:|---:|---:|---|
| 大标题 | `--text-display` | 62rpx | 600 | 1.25 | -0.8rpx | 每页最多一个（页面问候） |
| 大数字 | `--text-number` | 80rpx | 600 | 1.2 | -1.6rpx | 亮度百分比、dBm，tabular |
| 区块标题 | `--text-heading` | 48rpx | 600 | 1.25 | -0.8rpx | 「色温」「定时计划」级别 |
| 卡片标题 | `--text-card` | 40rpx | 600 | 1.38 | 0 | 卡片内标题、设备名 |
| 正文 | `--text-body` | 32rpx | 400 | 1.5 | 0 | 默认正文 |
| 辅助 | `--text-secondary` | 28rpx | 400 | 1.45 | 0 | 副标题、日期、元信息 |
| 微标签 | `--text-label` | 24rpx | 500 | 1.2 | 0.05em | 区块眉标、chips、元数据（**必带 4px 彩点前缀时用它**） |
| 说明 | `--text-caption` | 20rpx | 400 | 1.4 | 0.05em | 脚注 |

字重只用 **400 / 500 / 600**。微标签（`--text-label`）是唯一用 500 的角色；
不用 700（过重）。

## 4. 颜色

中性是 99% 的页面。彩色只允许三种出现形式：**一个 8rpx 圆点、一条 2rpx 描边、一处渐变卡**。

### 表面（由冷到暖只有一个例外）

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#F7F7F9` | 页面底色（Linen 画布） |
| `--surface` | `#FFFFFF` | 白卡：主卡、行卡 |
| `--surface-nested` | `#F2F2F2` | 卡内嵌套面（Ash） |
| `--surface-warm` | `#FFF9ED` | 唯一暖卡：每页最多一张特色卡（Cream） |
| `--hairline` | `#DEDEE0` | 发丝分隔线（Pearl） |

### 文字

| 变量 | 值 | 用途 |
|---|---|---|
| `--text-primary` | `#000000` | 标题、强边（Ink——**只给标题，不给正文**） |
| `--text-body` | `#333333` | 正文与工作边（Graphite，出现最多的颜色） |
| `--text-secondary` | `#707070` | 次级标题、微标签（Slate） |
| `--text-tertiary` | `#949494` | 占位、禁用（Fog） |
| `--text-on-dark` | `#FFFFFF` | 深底上的文字 |
| `--text-on-dark-muted` | `rgba(255,255,255,0.64)` | 深底上的次要文字 |

### 彩色标点（全部配给制）

| 变量 | 值 | 用途 |
|---|---|---|
| `--accent` | `#6366F1` | 紫罗兰：选中态、链接 chip、活跃描边（Iris Glow） |
| `--accent-wash` | `#EFF0FF` | 选中/悬停的光晕底（Lavender Mist） |
| `--link` | `#1685C7` | 信号蓝：可点链接文字（**不得当主 CTA**） |
| `--dot-active` | `#E92F48` | 故障圆点：未连接、设备离线、权限缺失（Ember Red，**只表故障**） |
| `--grad-warm` | `linear-gradient(16deg, #FF4D79, #FF8040 85%)` | 珊瑚渐变：**每页最多一张**特色卡 |
| `--on-grad` | `#FFFFFF` | 渐变卡上的文字 |

**规则**：
- 彩色分两类：**控件色**（开关、滑块、选中描边、按钮描边——表达「可操作 / 已选中」）与**标点色**（状态圆点、链接、渐变卡）。控件色只出现在控件本体上，不铺底。
- 装饰性彩色每个区块最多一种形式：一个点、或一条描边、或一张渐变卡。
- 深棕深底卡（原深棕主卡）废除；「当前主角」改用 Paper 白卡 + `--accent` 2rpx 描边 + `--accent-wash` 底表达。
- 绿色语义（成功）不设专门色：成功态用微标签 + 文字表达。
- 错误用 `--dot-active` 圆点 + 文字，不铺红底。
- 不用颜色单独传达状态，必须同时有文字或图标。
- 界面标题用 Ink，正文一律 Graphite。

## 5. 圆角

| 用途 | 值 |
|---|---:|
| 特色渐变卡 | 64rpx |
| 标准卡片（widget 卡） | 36rpx |
| 图片/输入框 | 24rpx |
| 图标 | 8rpx |
| 胶囊（按钮、chips、导航项） | 9999rpx |

## 6. 层次与阴影

**不用阴影**（对参考稿的偏离，见 §1）。层次靠三条：

1. **表面色阶**：`--bg`（画布）→ `--surface`（白卡）→ `--surface-nested`（卡内嵌套）
2. **发丝线**：2rpx `--hairline`，左侧内缩 32rpx
3. **彩色标点**：当前主角用 `--accent` 描边 + `--accent-wash` 底，其余一律白卡

**卡片最多两级嵌套。** 不允许卡片里再套卡片。

## 7. 控件

### 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主 | **描边胶囊**：透明底 + 2rpx `--accent` 描边 + `--accent` 文字 | 每屏最多一个（参考稿：不填色） |
| 渐变 | 填充 `--grad-warm`，白字，胶囊 | 每页最多一张的确认类动作 |
| 次 | 填充 `--surface-nested`，文字 `--text-body`，胶囊 | 并列次要动作 |
| 文字 | 无底，文字 `--link` | 轻量动作（「查看详情」） |
| 危险 | 无底，文字 `--dot-active` | 删除 |

高度 88rpx，字号 32rpx，胶囊圆角。并列按钮之间 16rpx。

### 开关

用原生 `switch`，`color` 设为 `--accent`。不自绘——原生动效与无障碍都更好。

### 滑块

轨道 6rpx 高；未填充 `--hairline`、已填充 `--accent`。滑块直径 40rpx，白色。

### 分段选择

胶囊并排：未选中用 `--surface-nested` 底 + `--text-secondary` 文字；
选中用 `--accent-wash` 底 + `--accent` 文字 + 2rpx `--accent` 描边。

### 列表行

定时计划类：一行一张白卡（`--surface`，36rpx 圆角，内边距 32rpx），行间 24rpx。
灯链/设备清单类：白卡 + 36rpx 圆角；卡片左上角允许一枚 8rpx `--dot-active` 圆点做「工作」标点。

### 底部导航

**胶囊浮条**（参考稿 Pill Navigation）：白底胶囊浮在底部，当前项为文字前 8rpx
`--accent` 圆点，其余项 `--text-secondary`。胶囊高 96rpx，内边距 24rpx。
**Ember Red 只表示故障与未连接**，不得用于「当前选中」。

### 微标签（Tracked Label）

`--text-label`（24rpx / 500 / 0.05em）+ 前缀 8rpx 彩色圆点（`--accent` / `--dot-active`）+ 12rpx 间距。
区块眉标、列表元数据、状态行的唯一写法。

## 8. 动效

| 项 | 值 |
|---|---|
| 时长 | 200ms（小控件）/ 280ms（页面转场）/ 320ms（较大面积） |
| 曲线 | `cubic-bezier(0.32, 0.72, 0, 1)` |
| 入场 | `opacity 0→1` + `translateY(8rpx→0)` |
| 按下 | `scale(0.97)`，120ms |
| 展开 | 高度或透明度过渡，不弹跳 |

**不做**：视差、滚动监听触发的动画、超过 400ms 的装饰动画、自动轮播、闪烁。

`prefers-reduced-motion: reduce` 时全部动效降为 0ms，且不得有元素因此不可见。

## 9. 文案

- **按钮 = 动词 + 宾语**。「保存布局」「删除设备」，不用「确定」「提交」
- **标题 = 名词短语**。「灯链」「部位」，不用「这里是灯链」
- 数字与单位之间留一个空格：`30 颗`、`500 ms`、`12.4 kWh`
- 不用感叹号，不用「请」，不用「您的」
- 空态必须给下一步动作：「还没有部位。添加第一个 →」
- 错误信息说**是什么 + 怎么办**，不说「操作失败」

## 10. 禁令

1. 装饰性渐变（`--grad-warm` 特色卡除外，且每页最多一张）、玻璃拟态、霓虹光晕
2. 彩色大面积铺底（`--accent-wash` 光晕除外）
3. 卡片超过两级嵌套
4. emoji 当图标
5. 页面样式里出现 hex 或字号硬编码（必须走变量与本文的字号表）
6. 可点元素小于 88rpx
7. 给卡片加投影
8. 用颜色单独传达状态（必须同时有文字或图标）
9. 正文用纯黑（`#000000`）——Ink 只给标题与强边，正文一律 `--text-body`
10. 彩色填色按钮（主按钮是描边胶囊，不是填色块）

## 11. 灯效预览的特殊规则

灯效预览区是**内容**，不是界面。它是全项目唯一允许：
- 出现任意颜色
- 铺满屏幕的纯色/动态区域
- 不受配给制限制
- 使用渐变

但预览区的**边框、标签、控件**仍受本文约束。

## 12. 与 Pixso 的对应

设计稿只画到**结构与关键态**（见 `AGENTS.md` 设计流程）：
- 页面区块划分与层级
- 空态 / 加载 / 错误 / 选中 四种态
- 颜色用本文的变量名标注，不标 hex

不画像素级细节——rpx 换算与字体渲染差异会让设计稿好看真机不对。
