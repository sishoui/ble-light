# 设计规范

暖调家居风格：米白画布、深棕主卡、焦糖色强调、照片媒体卡。
**设备与场景是主角（照片与大数字），界面退成安静的暖中性底。**

> **所有页面样式必须引用本文定义的变量，禁止手写颜色值与字号。**
> 改视觉先说清改哪一条，改完回来改这里，再改代码。

## 1. 适用与偏离

参照暖调智能家居的视觉体系（参考稿已确认），针对微信小程序做三处偏离：

| 偏离 | 参考稿 | 本项目值 | 原因 |
|---|---|---|---|
| 字体 | 定制圆润无衬线 | 系统栈 | 小程序不能打包字体；PingFang SC 是最接近的系统中文字体 |
| 字号 | px 直接标注 | rpx（1px ≈ 2rpx） | 小程序 750rpx = 视口宽，等比换算 |
| 阴影 | 几乎无 | 完全无 | 层次全靠色温差与留白，渲染代价也更低 |

其余照参考稿：米白画布、深棕卡片、焦糖开关与滑块、照片卡上的渐变压字、胶囊导航。

## 2. 布局

**8pt 网格**，在 WXSS 里是 16rpx 的倍数。

| 项 | 值 | 说明 |
|---|---|---|
| 页面左右边距 | 32rpx | 全项目统一，不按页面调 |
| 卡片内边距 | 32rpx | 大卡片；小控件 24rpx |
| 卡片间距 | 24rpx | 同一组内 |
| 区块间距 | 48rpx | 有标题分隔的段落之间 |
| 标题与内容间距 | 16rpx | 标题下方 |
| 最小触摸区 | 88rpx | 44pt，**任何可点元素不得小于此** |
| 页面底部留白 | `calc(160rpx + env(safe-area-inset-bottom))` | 给 tabBar 让位 |

## 3. 字体

```
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif;
```

数字（亮度、能耗、温度、计数）加 `font-variant-numeric: tabular-nums`。

| 角色 | 变量 | 字号 | 字重 | 行高 | 用途 |
|---|---|---:|---:|---:|---|
| 页面问候 / 大标题 | `--text-title` | 44rpx | 600 | 1.3 | 每页最多一个 |
| 大数字 | `--text-number` | 44rpx | 600 | 1.2 | 能耗、亮度百分比，tabular |
| 区块标题 | `--text-heading` | 34rpx | 600 | 1.4 | 「快速控制」「色温」级别 |
| 卡片标题 | `--text-card` | 32rpx | 600 | 1.4 | 卡片内标题、设备名 |
| 正文 | `--text-body` | 30rpx | 400 | 1.5 | 默认正文 |
| 辅助 | `--text-secondary` | 26rpx | 400 | 1.45 | 副标题、日期、元信息 |
| 说明 | `--text-caption` | 22rpx | 400 | 1.4 | 脚注、标签、chips |

字重只用 **400 / 600**。不用 500（中文字体的 500 渲染不一致），不用 700（过重）。

## 4. 颜色

暖中性是底，焦糖是唯一的强调色。深棕只用于「当前主角」卡（主灯控制、选中项）。

### 表面

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#F7F3EC` | 页面底色（暖米白） |
| `--surface` | `#FFFFFF` | 白卡：定时行、统计卡 |
| `--surface-warm` | `#EFE8DD` | 暖卡：快速控件、次级区块 |
| `--card-dark` | `#372E25` | 深棕主卡：主灯控制、选中态 |
| `--hairline` | `#E9E2D6` | 分隔线（暖） |

### 文字

| 变量 | 值 | 用途 |
|---|---|---|
| `--text-primary` | `#322A20` | 主文字（深咖） |
| `--text-secondary` | `#8B7F6F` | 次要文字、日期 |
| `--text-tertiary` | `#B9AE9C` | 占位、禁用 |
| `--on-dark` | `#FFFFFF` | 深棕卡上的主文字 |
| `--on-dark-muted` | `rgba(255,255,255,0.64)` | 深棕卡上的次要文字 |

### 强调与语义

| 变量 | 值 | 用途 |
|---|---|---|
| `--accent` | `#D89A63` | 焦糖：开关开态、滑块、选中描边、进行中标签 |
| `--accent-press` | `#C4854E` | 焦糖按下态 |
| `--accent-soft` | `#F4E6CF` | 浅焦糖底：暖光 chip、高亮行 |
| `--cool-soft` | `#E3EDF7` | 冷光 chip 底（唯一允许的冷色块） |
| `--ok` | `#8BAB8E` | 成功、门锁已锁 |
| `--error` | `#C05A3C` | 错误（暖赭，不用刺眼红） |
| `--scrim` | `rgba(20,14,8,0.55)` | 照片卡底部压字渐变的终点色 |

**规则**：
- 强调色只有焦糖一个。绿色只表达「已锁/成功」，蓝色只出现在冷光 chip。
- 界面不用纯黑；最深的色是深棕 `--card-dark` 与文字 `--text-primary`。
- 不用颜色单独传达状态，必须同时有文字或图标。

### 照片媒体卡

- 圆角 40rpx，图片 `aspect-ratio` 固定，`mode="aspectFill"`。
- 底部压字：从透明渐变到 `--scrim`，白字落在渐变上。
- 卡上小标签：半透明白底（`rgba(255,255,255,0.85)`）或半透明深底胶囊，22rpx。

## 5. 圆角

| 用途 | 值 |
|---|---:|
| 照片媒体卡、深棕主卡 | 40rpx |
| 标准卡片（定时行、统计卡、快速控件） | 32rpx |
| 小控件、输入框 | 24rpx |
| 胶囊（按钮、chips、开关、导航项） | 9999rpx |

## 6. 层次与阴影

**不用阴影。** 层次靠三条：

1. **色温差**：`--bg`（米白）→ `--surface-warm`（暖卡）→ `--surface`（白卡）→ `--card-dark`（深棕）
2. **分隔线**：2rpx `--hairline`，左侧内缩 32rpx
3. **深浅对比**：当前主角用 `--card-dark`，其余一律浅色

**卡片最多两级嵌套。** 不允许卡片里再套卡片。

## 7. 控件

### 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主 | 填充 `--card-dark`，文字白，胶囊 | 每屏最多一个 |
| 焦糖 | 填充 `--accent`，文字白，胶囊 | 开始/确认类动作 |
| 次 | 填充 `--surface-warm`，文字 `--text-primary`，胶囊 | 并列次要动作 |
| 文字 | 无底，文字 `--text-secondary` | 轻量动作（「查看详情」） |
| 危险 | 无底，文字 `--error` | 删除 |

高度 88rpx，字号 30rpx，胶囊圆角。并列按钮之间 16rpx。

### 开关

用原生 `switch`，`color` 设为 `--accent`。不自绘——原生动效与无障碍都更好。
门锁等「安全态」用 `--ok`。

### 滑块

轨道 6rpx 高；深棕卡上未填充部分 `rgba(255,255,255,0.24)`、已填充 `--accent`；
浅底上未填充 `--hairline`、已填充 `--accent`。滑块直径 40rpx，白色。

### 色温 / 分段选择

三个胶囊并排：未选中用浅底（暖光 `--accent-soft`、自然光 `--surface-warm`、冷光 `--cool-soft`）+
各自深色文字；选中用 `--card-dark` 白字并加 2rpx `--accent` 描边。

### 列表行

定时计划类：一行一张白卡（`--surface`，32rpx 圆角，内边距 24rpx），行间 16rpx。
灯链/设备清单类：无卡片底，分隔线用 `--hairline` 左侧内缩 32rpx。

### 底部导航

自建 tabBar：背景 `--bg`，当前项为 `--card-dark` 胶囊（白图标白字），
其余项透明底 `--text-secondary`。胶囊高 88rpx，内边距 24rpx。

### 标签 chips

22–24rpx，胶囊。照片卡上用半透明底；列表里用 `--accent-soft` 底 + 深咖文字。

## 8. 动效

| 项 | 值 |
|---|---|
| 时长 | 200ms（小控件）/ 280ms（页面转场）/ 320ms（较大面积） |
| 曲线 | `cubic-bezier(0.32, 0.72, 0, 1)` |
| 入场 | `opacity 0→1` + `translateY(8rpx→0)` |
| 按下 | `scale(0.97)`，120ms |
| 展开 | 高度或透明度过渡，不弹跳 |

**不做**：视差、滚动监听触发的动画、超过 400ms 的装饰动画、自动轮播、闪烁。

`prefers-reduced-motion: reduce` 时全部动效降为 0ms，且不得有元素因此不可见。

## 9. 文案

- **按钮 = 动词 + 宾语**。「保存布局」「删除设备」，不用「确定」「提交」
- **标题 = 名词短语**。「灯链」「部位」，不用「这里是灯链」
- 数字与单位之间留一个空格：`30 颗`、`500 ms`、`12.4 kWh`
- 不用感叹号，不用「请」，不用「您的」
- 空态必须给下一步动作：「还没有部位。添加第一个 →」
- 错误信息说**是什么 + 怎么办**，不说「操作失败」

## 10. 禁令

1. 装饰性渐变（照片卡压字渐变除外）、玻璃拟态、霓虹光晕
2. 荧光色、饱和纯蓝/纯绿大面积铺底
3. 卡片超过两级嵌套
4. emoji 当图标
5. 页面样式里出现 hex 或字号硬编码（必须走变量与本文的字号表）
6. 可点元素小于 88rpx
7. 给卡片加投影
8. 用颜色单独传达状态（必须同时有文字或图标）
9. 界面用纯黑（`#000000`）；最深只允许 `--card-dark` 与 `--text-primary`

## 11. 灯效预览的特殊规则

灯效预览区是**内容**，不是界面。它是全项目唯一允许：
- 出现任意颜色
- 铺满屏幕的纯色/动态区域
- 不受强调色限制
- 使用渐变

但预览区的**边框、标签、控件**仍受本文约束。

## 12. 与 Pixso 的对应

设计稿只画到**结构与关键态**（见 `AGENTS.md` 设计流程）：
- 页面区块划分与层级
- 空态 / 加载 / 错误 / 选中 四种态
- 颜色用本文的变量名标注，不标 hex

不画像素级细节——rpx 换算与字体渲染差异会让设计稿好看真机不对。
