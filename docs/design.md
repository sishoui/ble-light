# 设计规范

苹果风格的克制感：界面让位于内容，层次靠留白与明度差，不靠装饰。

> **所有页面样式必须引用本文定义的变量，禁止手写颜色值与字号。**
> 改视觉先说清改哪一条，改完回来改这里，再改代码。

## 1. 适用与偏离

本文按 Apple HIG 的**结构与气质**执行，在三处刻意偏离，原因写在括号里：

| 偏离 | Apple 值 | 本项目值 | 原因 |
|---|---|---|---|
| 正文字号 | 17pt | 15pt（30rpx） | 中文在 17pt 下视觉偏大，微信小程序惯例是 28–32rpx |
| 字体 | SF Pro | 系统栈 | 小程序不能打包字体；iOS 上 PingFang SC 本身就是苹果的中文字体 |
| 毛玻璃 | 广泛使用 | 不用 | Android 对 `backdrop-filter` 支持不稳，改用明度差做层次 |

其余照 HIG：留白、层级、44pt 触摸区、克制的强调色、有目的的动效。

## 2. 布局

**8pt 网格**，在 WXSS 里是 16rpx 的倍数。

| 项 | 值 | 说明 |
|---|---|---|
| 页面左右边距 | 32rpx | 全项目统一，不按页面调 |
| 卡片内边距 | 32rpx | 大卡片；小控件 24rpx |
| 卡片间距 | 24rpx | 同一组内 |
| 区块间距 | 48rpx | 有标题分隔的段落之间 |
| 标题与内容间距 | 16rpx | 标题下方 |
| 最小触摸区 | 88rpx | 44pt，**任何可点元素不得小于此** |

底部要为 tabBar 让出 `calc(160rpx + env(safe-area-inset-bottom))`。

## 3. 字体

```
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif;
```

数字（亮度值、温度、时间、计数）加 `font-variant-numeric: tabular-nums`，避免跳动。

| 角色 | 字号 | 字重 | 行高 | 用途 |
|---|---:|---:|---:|---|
| 大标题 | 68rpx | 600 | 1.2 | 页面标题，每页最多一个 |
| 标题 | 44rpx | 600 | 1.25 | 区块标题 |
| 小标题 | 34rpx | 600 | 1.3 | 卡片标题 |
| 正文 | 30rpx | 400 | 1.5 | 主体文字 |
| 辅助 | 26rpx | 400 | 1.45 | 说明、副标题 |
| 说明 | 22rpx | 400 | 1.4 | 脚注、标签 |

字重只用 **400 / 600**。不用 500（中文字体的 500 渲染不一致），不用 700（过重）。

## 4. 颜色

深色为默认，浅色跟随系统。**所有颜色走 CSS 变量，禁止 hex 进页面样式。**

### 深色

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#000000` | 页面底色（OLED 纯黑，省电且边界消失） |
| `--surface-1` | `#1C1C1E` | 卡片 |
| `--surface-2` | `#2C2C2E` | 卡片内的次级区块、输入框 |
| `--surface-3` | `#3A3A3C` | 被按下的控件、选中态底 |
| `--label` | `rgba(255,255,255,0.98)` | 主文字 |
| `--label-2` | `rgba(235,235,245,0.60)` | 次要文字 |
| `--label-3` | `rgba(235,235,245,0.30)` | 占位、禁用 |
| `--separator` | `rgba(84,84,88,0.60)` | 分隔线 |

### 浅色

| 变量 | 值 |
|---|---|
| `--bg` | `#F2F2F7` |
| `--surface-1` | `#FFFFFF` |
| `--surface-2` | `#F2F2F7` |
| `--surface-3` | `#E5E5EA` |
| `--label` | `#000000` |
| `--label-2` | `rgba(60,60,67,0.60)` |
| `--label-3` | `rgba(60,60,67,0.30)` |
| `--separator` | `rgba(60,60,67,0.29)` |

### 强调与状态

| 变量 | 值 | 用途 |
|---|---|---|
| `--accent` | `#6B8CAE` | 主色（雾蓝）。低饱和，不与灯效抢眼 |
| `--accent-press` | `#5A7A9A` | 按下态 |
| `--accent-soft` | `#8FA9C4` | 深色底上的链接与次要强调 |
| `--ok` | `#30D158` | 成功、已连接 |
| `--warn` | `#FF9F0A` | 警告、部分完成 |
| `--err` | `#FF453A` | 错误、危险操作 |

**强调色只有一个。** 灯效预览里的颜色是内容，不是界面色，不受此限。

## 5. 圆角

| 用途 | 值 |
|---|---:|
| 大卡片 | 24rpx |
| 小控件、输入框 | 16rpx |
| 按钮 | 20rpx |
| 胶囊按钮、标签 | 999rpx |
| 方形图标 | 18rpx |

Apple 用连续圆角（squircle），小程序只能 `border-radius` 做圆角——接受这个近似，不要用多层嵌套去模拟。

## 6. 层次与阴影

**深色下不用阴影，用明度差。** `--bg` → `--surface-1` → `--surface-2` 三级已经足够表达从属关系。

浅色下用极淡阴影：
```
box-shadow: 0 2rpx 12rpx rgba(0, 0, 0, 0.06);
```

不用 `backdrop-filter`（见 §1）。

**卡片最多两级嵌套。** `surface-1` 里放 `surface-2`，不许再往下嵌 `surface-3`。

## 7. 控件

### 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主 | 填充 `--accent`，文字白色 | 每屏最多一个，是主要动作 |
| 次 | 填充 `--surface-2`，文字 `--label` | 并列的次要动作 |
| 文字 | 无底，文字 `--accent-soft` | 破坏性低、不占视觉重量的动作 |
| 危险 | 填充 `--surface-2`，文字 `--err` | 删除 |

高度 88rpx，字号 30rpx，圆角 20rpx。并列按钮之间 16rpx。

### 开关

用原生 `switch`，`color` 设为 `--accent`。不自绘——原生动效与无障碍都更好。

### 滑块

轨道 4rpx 高，`--surface-3`；已填充部分 `--accent`；滑块直径 44rpx，白色，带极淡阴影。

### 列表行

高 96rpx，左文字右值/箭头，分隔线用 `--separator` 且**左侧内缩 32rpx**（与 Apple 列表一致）。

## 8. 动效

| 项 | 值 |
|---|---|
| 时长 | 200ms（小控件）/ 280ms（页面转场）/ 320ms（较大面积） |
| 曲线 | `cubic-bezier(0.32, 0.72, 0, 1)` |
| 入场 | `opacity 0→1` + `translateY(8rpx→0)` |
| 按下 | `scale(0.97)`，120ms |
| 展开 | 高度或透明度过渡，不弹跳 |

**不做**：视差、滚动监听触发的动画、超过 400ms 的装饰动画、自动轮播、闪烁。

`prefers-reduced-motion: reduce` 时全部动效降为 0ms，且不得有元素因此不可见。

## 9. 文案

- **按钮 = 动词 + 宾语**。「保存布局」「删除设备」，不用「确定」「提交」
- **标题 = 名词短语**。「灯链」「部位」，不用「这里是灯链」
- 数字与单位之间留一个空格：`30 颗`、`500 ms`
- 不用感叹号，不用「请」，不用「您的」
- 空态必须给下一步动作：「还没有部位。添加第一个 →」
- 错误信息说**是什么 + 怎么办**，不说「操作失败」

## 10. 禁令

1. 装饰性渐变、玻璃拟态、霓虹光晕
2. 紫色、品红、荧光色
3. 卡片超过两级嵌套
4. emoji 当图标
5. 页面样式里出现 hex 或 rpx 字号硬编码（必须走变量与本文的字号表）
6. 可点元素小于 88rpx
7. 纯色大色块铺满屏幕（灯效预览除外）
8. 用颜色单独传达状态（必须同时有文字或图标）

## 11. 灯效预览的特殊规则

灯效预览区是**内容**，不是界面。它是全项目唯一允许：
- 出现任意颜色
- 铺满屏幕的纯色/动态区域
- 不受强调色限制

但预览区的**边框、标签、控件**仍受本文约束。

## 12. 与 Pixso 的对应

设计稿只画到**结构与关键态**（见 `AGENTS.md` 设计流程）：
- 页面区块划分与层级
- 空态 / 加载 / 错误 / 选中 四种态
- 颜色用本文的变量名标注，不标 hex

不画像素级细节——rpx 换算与字体渲染差异会让「设计稿好看、真机不对」。
