# 0001 领域模型沿用 lumen v5

## 背景

lumen 在 10 天内走了五轮，模型从「单灯带单色」演进到「设备 → 灯链 → 部位 → 场景 → 步骤 → 层」。v5 是一次断崖式重构：删掉段表与剧本表，用部位 + 三场景 + 每部位独立播放头取代。

这次重写的动机是文档与测试失控，不是模型错了。

## 决策

**完整沿用 v5 的领域模型，不做重新设计。**

- 灯链上划部位（≤8），部位由段（≤8）组成，一颗灯珠只属一个部位
- 三个场景，每个场景里每个部位有独立时间轴（≤8 步，每步 ≤2 层）
- 播放头只存 `origin_ms`，步号由闭式解算出，不做累加
- 未被任何部位覆盖的灯珠恒黑

## 后果

- 术语表（`GLOSSARY.md`）直接继承，不从零造词
- 重写工作集中在实现质量与文档工艺，不承担模型探索风险
- 继承 v5 的已知取舍：8 链 × 100 颗上限、场景固定 3 个、切换是硬切

## 备选

- **重新设计模型**：否决。五轮打磨出的模型是最贵的资产，重来一遍等于把踩过的坑再踩一遍。
- **简化到单场景单时间轴**：否决。多场景是产品核心能力，不是可选项。
