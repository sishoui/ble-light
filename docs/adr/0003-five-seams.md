# 0003 只测五个接缝，测行为不测结构

## 背景

lumen 最终有 61 个测试文件 / 1,203 用例 / 20,087 行。其中：

- **37 个 `it` 断言源码文本**（读 `.ts` 文件、正则匹配「页面里不能出现 `buildEffectPanel(`」）
- **25 个文件 / 425 用例依赖 Mock/Fake**，`mock-mode.test.ts` 用 94 个 `expect` 断言 mock 等于 mock 自己的 seed
- **125 个用例硬编码字节偏移**（`payload[27]`、`toBe(0x..)`）
- 历史上**删掉过 39 个测试文件**，v5 那一个 commit 一次删 33 个，同一天又补回 5 个，commit message 写「补回『行为还在但测试没了』的六类用例」

根因：测试跟着**模型**走。模型一换（v5 断崖），大批测试同时失去意义，只能删。而断言源码文本的测试，重构就红、行为坏了反而绿。

## 决策

**测试只挂在五个接缝上，且只断言行为。**

| # | 接缝 | 断言什么 |
|---|---|---|
| 1 | 协议编解码 | 字节布局，唯一允许断言字节的地方 |
| 2 | 命令 reducer | `(state, cmd) → (state', result, intents)` |
| 3 | 渲染合成 | 像素 |
| 4 | 会话层 | 设备收到了什么（`transport.writes`） |
| 5 | 页面处理器 | 用户看得见的结果 |

**三条禁令**：

1. 禁止读源文件做断言
2. 禁止 mock 自证
3. 禁止 fixture 快照当行为测试

**测试不许因为重构而删。** 红了先问行为变了吗；行为没变就是接缝选错，改接缝。

## 后果

- 用例总数会远低于 lumen（预计 200–400 而非 1,203），但每个都在测产品行为
- 页面视觉细节（布局、颜色）不进单测，由 `ui` 层和真机验收覆盖
- 新增模块时必须先回答「它属于哪个接缝」，回答不出就不写测试

## 备选

- **按目录组织测试**：lumen 就是这样，导致测试跟着目录重组被删。否决。
- **覆盖率驱动**：覆盖率会奖励测私有函数，与禁令冲突。否决。
