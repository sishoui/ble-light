# 0004 v1 不包含后端

## 背景

lumen 有 `server/`：Fastify + SQLite，做使用日志、设备登记、只读看板。它和控制链路**完全无关**——控制始终是手机 ↔ 设备 BLE 直连。

但它带来持续的维护成本：4 张表 + 2 个视图 + 迁移、140 个测试用例、`code2session` 身份回落、幂等补报、离线队列。每一轮改协议它都不需要动，但每轮都要确认它没坏。

## 决策

**v1 不建 `server/`。** 使用统计与设备登记全部不做。

## 后果

- 少一个包、少一套依赖、少 140 个用例
- 没有使用数据看板——需要时用真机日志和串口统计替代
- 将来要做，单开一个仓库，通过一个明确的 HTTP 接口接入，不放进这个 monorepo

## 备选

- **保留后端但只做日志**：仍然要维护 schema 与鉴权。否决。
- **先做后端再做产品**：本末倒置。否决。
